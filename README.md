# Dashboard ความพึงพอใจผู้บริจาคเลือด (ในสถานที่) ปีงบประมาณ 2570

หน้ารายงานสำหรับอาจารย์และเจ้าหน้าที่ เปิดผ่าน GitHub Pages มีหน้า Login อ่านข้อมูลจาก Google Sheet แบบอ่านอย่างเดียว

**ลิงก์ Dashboard:** <https://nuttawit61.github.io/Donationcentersurvey/dashboard/>

| ไฟล์ | อยู่ที่ไหน |
|---|---|
| `index.html` | GitHub (โฟลเดอร์ `dashboard/`) — หน้า Dashboard |
| `Code.gs` | Apps Script โปรเจกต์ใหม่ — ตรวจรหัสผ่านและส่งข้อมูลจากชีต |

ทำงานอย่างไร: หน้า Dashboard บน GitHub ไม่มีข้อมูลอยู่ในตัว เมื่อใส่รหัสผ่านถูก Apps Script จะส่งข้อมูลจาก Google Sheet มาให้ ผู้ที่ไม่มีรหัสผ่านจะไม่ได้รับข้อมูลใด ๆ

## ติดตั้ง (ทำครั้งเดียว)

### ก. Apps Script

1. ไปที่ <https://script.google.com> ด้วยบัญชีที่เป็นเจ้าของชีตคำตอบ > **โปรเจกต์ใหม่**
   ตั้งชื่อเช่น `Dashboard API ความพึงพอใจ 2570` (แยกจากโปรเจกต์แบบสอบถาม)
2. ลบโค้ดเดิม แล้ววางเนื้อหา `Code.gs` จากโฟลเดอร์นี้
3. แก้ `SPREADSHEET_URL` ด้านบน — วางลิงก์ Google Sheet ที่เก็บคำตอบ
   (ไฟล์ที่แก้แล้วนี้ **ห้ามอัปขึ้น GitHub** — วางไว้ใน Apps Script อย่างเดียว)
4. **ตั้งรหัสผ่าน:** ⚙️ **การตั้งค่าโปรเจกต์** > **คุณสมบัติของสคริปต์** > **เพิ่มคุณสมบัติของสคริปต์**
   - คุณสมบัติ: `DASHBOARD_PASSWORD` · ค่า: `รหัสผ่านที่ใช้` > **บันทึก**
5. เลือกฟังก์ชัน `testConnection` > **เรียกใช้** > อนุญาตสิทธิ์ ต้องเห็น "เชื่อมต่อสำเร็จ … มีคำตอบ N แถว"
6. **การทำให้ใช้งานได้ > การทำให้ใช้งานได้รายการใหม่ > เว็บแอป**
   - เรียกใช้ในฐานะ: **ฉัน**
   - ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน** (จำเป็น เพื่อให้หน้าบน GitHub เรียกได้ — ข้อมูลยังถูกป้องกันด้วยรหัสผ่าน)
7. คัดลอกลิงก์ `/exec`

### ข. GitHub

1. `dashboard/index.html` ตั้งค่า `DASHBOARD_API_URL` ไว้แล้ว ถ้าสร้าง deployment ใหม่ (ลิงก์ `/exec` เปลี่ยน) ให้แก้บรรทัดนี้ให้ตรงกัน
2. รอ 1–2 นาที แล้วเปิด <https://nuttawit61.github.io/Donationcentersurvey/dashboard/>

## การใช้งาน

มี 3 เมนูด้านบน ตัวกรองวันที่ / ช่วงอายุ / ประสบการณ์ ใช้ร่วมกันทุกเมนู

| เมนู | ใช้ทำอะไร |
|---|---|
| 📊 **ภาพรวม** | ตัวชี้วัด กราฟรายวัน ตารางสีจุดบริการ รายงานรายวัน และความคิดเห็นล่าสุด 3 รายการ |
| 📋 **ข้อมูลดิบ** | ตาราง 1 แถว = ผู้ตอบ 1 คน ครบทุกข้อ ค้นหา เรียงลำดับ แบ่งหน้า กรองเฉพาะผู้ที่คะแนนรวมไม่เกิน 4 ได้ · ช่องสีชมพู = ให้ 1–2 คะแนน · ชี้หัวคอลัมน์ (ลท1, คก2 …) เพื่อดูข้อคำถาม |
| 💬 **ความคิดเห็น** | ข้อความที่ผู้ตอบพิมพ์ทั้งหมด กรองตามหัวข้อ ค้นหาคำ (ไฮไลต์คำที่พบ) เรียงตามคะแนนต่ำสุดก่อนได้ และดาวน์โหลดเป็น CSV |

- เปิดครั้งแรกแสดง **วันนี้** เลือกช่วงอื่นได้: เมื่อวาน, 7 วัน, 30 วัน, เดือนนี้, ทั้งปีงบ 2570 หรือกำหนดวันที่เอง
- คลิกแท่งกราฟหรือแถวในตารางรายงานรายวัน เพื่อดูเฉพาะวันนั้น · คลิกชื่อจุดบริการในตารางสี เพื่อดูคะแนนรายข้อ
- **รีเฟรช** โหลดข้อมูลล่าสุด · **ดาวน์โหลด CSV** (เปิดใน Excel ภาษาไทยถูกต้อง) · **พิมพ์ / PDF**

## หน้า Login

- เข้าสู่ระบบแล้วจะจำไว้จนกว่าจะปิดแท็บ กด “ออกจากระบบ” หรือครบ 6 ชั่วโมง
- ใส่รหัสผิดรวม 10 ครั้ง ระบบจะล็อก 10 นาที
- **เปลี่ยนรหัสผ่าน:** แก้ค่า `DASHBOARD_PASSWORD` ในคุณสมบัติของสคริปต์ มีผลทันที ไม่ต้อง deploy ใหม่
- อย่าเขียนรหัสผ่านไว้ในไฟล์ใด ๆ บน GitHub (repository เป็นสาธารณะ)

## นิยามตัวชี้วัด

| ตัวชี้วัด | วิธีคำนวณ |
|---|---|
| คะแนนเฉลี่ยภาพรวม | ค่าเฉลี่ยคะแนนทุกข้อ (24 ข้อ) ของผู้ตอบทุกคนในช่วงที่เลือก |
| ร้อยละผู้ตอบที่คะแนนรวม > 4/5 | จำนวนผู้ตอบที่คะแนนเฉลี่ยของตนเองทั้ง 24 ข้อ **มากกว่า 4.00** ÷ ผู้ตอบทั้งหมด × 100 |
| ความพึงพอใจต่อบริการโดยรวม | ค่าเฉลี่ยข้อ "โดยรวมแล้ว ท่านพึงพอใจต่อบริการ…" |
| ตั้งใจกลับมา / แนะนำต่อ | ร้อยละที่ตอบ "แน่นอน" หรือ "น่าจะ" |
| ระดับคะแนน | 4.21–5.00 มากที่สุด · 3.41–4.20 มาก · 2.61–3.40 ปานกลาง · 1.81–2.60 น้อย · 1.00–1.80 น้อยที่สุด |

นับวันตาม **วันที่บริจาค** ที่ผู้ตอบระบุ (ไม่ใช่วันที่กดส่ง)
ถ้าต้องการนับ 4.00 พอดีเป็นพึงพอใจด้วย แก้ใน `index.html` บรรทัด `const SATISFIED_ABOVE = 4;` เป็น `3.999`

## เมื่อแก้ `Code.gs` ภายหลัง

**จัดการการทำให้ใช้งานได้ > ✏️ > เวอร์ชันใหม่ > ทำให้ใช้งานได้** (ลิงก์ `/exec` เดิมใช้ต่อได้ ไม่ต้องแก้ GitHub)

## แก้ปัญหา

| อาการ | สาเหตุ / วิธีแก้ |
|---|---|
| "ยังไม่ได้ตั้งค่า DASHBOARD_API_URL" | ยังไม่ได้ใส่ลิงก์ `/exec` ใน `dashboard/index.html` (ข้อ ข.1) |
| "เชื่อมต่อระบบไม่ได้" | ตั้ง "ผู้ที่มีสิทธิ์เข้าถึง" ไม่ใช่ **ทุกคน** หรือใช้ลิงก์ที่มี `/u/1/`, `/a/macros/` — ลิงก์ต้องขึ้นต้นด้วย `https://script.google.com/macros/s/` |
| "ผู้ดูแลยังไม่ได้ตั้งรหัสผ่าน" | ยังไม่ได้เพิ่ม `DASHBOARD_PASSWORD` (ข้อ ก.4) |
| "หมดเวลาการใช้งาน" | ครบ 6 ชั่วโมง เข้าสู่ระบบใหม่ |
| "ไม่พบคอลัมน์ …" | มีการแก้ชื่อหัวตารางในชีตคำตอบ ให้คืนชื่อเดิม |
| ข้อมูลไม่อัปเดต | กดปุ่ม **รีเฟรช** |
