# แบบประเมินความพึงพอใจ ศูนย์รับบริจาคเลือด (ในสถานที่) ปีงบประมาณ 2570

หน้าแบบสอบถามโฮสต์บน **GitHub Pages** และบันทึกคำตอบลง **Google Sheets** ผ่าน Google Apps Script Web App

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าแบบสอบถาม (ใช้ได้ทั้งบน GitHub Pages และเปิดผ่านลิงก์ Apps Script) |
| `Code.gs` | ตรวจคำตอบและบันทึกลง Google Sheets (`doPost` สำหรับ GitHub Pages, `doGet` สำหรับลิงก์ Apps Script) |

## 1. ตั้งค่า Google Sheet + Apps Script

1. สร้าง Google Sheet สำหรับเก็บคำตอบ
2. จากชีต เปิด **ส่วนขยาย > Apps Script** แล้ววางโค้ดจาก `Code.gs`
3. (ถ้าต้องการให้เปิดผ่านลิงก์ Apps Script ได้ด้วย) สร้างไฟล์ HTML ชื่อ `Index` แล้ววางเนื้อหา `index.html`
4. เลือกฟังก์ชัน `setupSurvey` แล้วกด **เรียกใช้** หนึ่งครั้ง และอนุญาตสิทธิ์ ระบบจะสร้างแท็บ **คำตอบแบบประเมิน 2570**
5. **การทำให้ใช้งานได้ > การทำให้ใช้งานได้รายการใหม่ > เว็บแอป**
   - เรียกใช้ในฐานะ: **ฉัน**
   - ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน** (ต้องเป็น "ทุกคน" ไม่ใช่ "ทุกคนที่มีบัญชี Google" มิฉะนั้นผู้ตอบจาก GitHub Pages จะส่งไม่ได้)
6. คัดลอก URL ที่ลงท้ายด้วย `/exec`

## 2. ตั้งค่าและอัปโหลดขึ้น GitHub

1. เปิด `index.html` แก้บรรทัด
   ```js
   const WEB_APP_URL = 'https://script.google.com/macros/s/PASTE_DEPLOYMENT_ID/exec';
   ```
   เป็น URL `/exec` จากขั้นตอนที่ 1
2. อัปโหลด `index.html`, `README.md`, `.gitignore` ขึ้น repository
3. **Settings > Pages > Source: Deploy from a branch** เลือก `main` / `/ (root)`
4. ลิงก์แบบสอบถามจะเป็น `https://<ชื่อผู้ใช้>.github.io/<ชื่อ-repo>/`

## 3. ทดสอบก่อนใช้จริง

- เปิดลิงก์ GitHub Pages ตอบจนจบ แล้วตรวจว่ามีแถวใหม่ในชีต
- ลบแถวทดสอบก่อนเริ่มเก็บข้อมูลจริง

## เมื่อแก้ไข `Code.gs` ภายหลัง

ต้อง **การทำให้ใช้งานได้ > จัดการการทำให้ใช้งานได้ > แก้ไข (ไอคอนดินสอ) > เวอร์ชัน: เวอร์ชันใหม่** เพื่อให้ URL เดิมใช้โค้ดใหม่ (ถ้าสร้าง deployment ใหม่ URL จะเปลี่ยน ต้องแก้ `WEB_APP_URL` ด้วย)

## ข้อมูลที่ระบบตรวจสอบฝั่งเซิร์ฟเวอร์

- ต้องให้ความยินยอม และตอบคะแนน 1–5 ครบทุกข้อ
- วันที่บริจาคอยู่ระหว่าง 1 ต.ค. 2569 ถึงวันนี้ (ปีงบประมาณ 2570)
- ข้อความยาวไม่เกิน 1,500 ตัวอักษร และป้องกันการแทรกสูตรในชีต
- มีช่องซ่อน (honeypot) กรองการส่งจากบอท

## ความเป็นส่วนตัว

- Repository นี้ไม่มีข้อมูลคำตอบ ข้อมูลอยู่ใน Google Sheet เท่านั้น — อย่าแชร์ชีตเป็นสาธารณะ
- ไม่ควรอัปโหลดไฟล์ Word, ภาพตัวอย่าง หรือไฟล์ส่งออกคำตอบขึ้น repository (ดู `.gitignore`)
